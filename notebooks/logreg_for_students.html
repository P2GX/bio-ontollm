NumPy and matrix operations

If you don’t know it, look it up and spend some time with it, especially if you are interested in machine learning, scientific computing and data science. NumPy is a pyhon library that provides efficient array and matrix operations with precompiled C and Fortran code to speed up computations while minimizing memory footprint. The regularization exercise did not use it when I first wrote it, and it was prohibitly slow (several minutes…) on a rather powerful machine (Apple Silicon M3 Max chip, 36GB RAM and 14 cores). Using numpy and matrix notation made it possible to run in 42 seconds.
